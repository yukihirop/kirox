KiroxRecycle .kiro CLI

CLI tool to fetch Kiro specification and steering files from remote GitHub repositories

Getting Started
GitHub
📦

Fetch Files from Remote Repositories

Automatically fetch all files from .kiro/specs/ and .kiro/steering/ directories in specified GitHub repositories

⚡

Instant Execution with npx

No global installation required, run immediately with npx kirox command

🛡️

Overwrite Protection

Confirmation prompt to prevent unintended overwriting of existing local files

📊

Progress Visualization

Real-time display of file fetching progress with summary of successes and failures upon completion

🎯

Flexible Configuration

Customize behavior with configuration file (.kiroxrc.json) and support for multiple options (--force, --dry-run, --verbose)

🔄

Update Tracking

Track changes in remote repositories and detect differences with local files

Key Features ​

  • Fetch files from remote repositories: Automatically fetch files from .kiro/specs/ and .kiro/steering/ directories
  • Overwrite protection: Confirmation prompt for existing files
  • Branch specification: Specify branches using owner/repo#branch format
  • Subdirectory support: Fetch from subdirectories within repositories
  • Shell completion: Support for bash, zsh, fish, and PowerShell

For more details, see the Guide.
