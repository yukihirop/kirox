# Implementation Plan

## タスク概要

本実装計画は、Kirox CLIのインタラクティブモードにおける全てのプロンプトメッセージに絵文字プレフィックスを追加する機能を実現する。9つのプロンプト地点に対して適切な絵文字を追加し、既存のテストを更新することで、視覚的に改善されたユーザー体験を提供する。

## 実装タスク

- [ ] 1. インタラクティブプロンプトメッセージに絵文字を追加する
- [x] 1.1 リポジトリ入力プロンプトに📦絵文字を追加する
  - `interactive-prompt.ts`の`promptRepository`関数のメッセージ文字列を更新する
  - メッセージ形式を「📦 Enter GitHub repository (owner/repo or owner/repo#branch)」に変更する
  - デフォルトリポジトリ提案時も絵文字が正しく表示されることを確認する
  - 既存のバリデーションロジックは一切変更しない
  - _要件: 1.1, 1.2, 1.3_

- [x] 1.2 プロジェクト名入力プロンプトに📋絵文字を追加する

  - メッセージ形式を「📁 Enter subdirectory in GitHub repository (optional)」に変更する

## 実装順序の根拠

1. **タスク1-3**: プロンプトメッセージの絵文字追加を論理的なグループ（インタラクティブプロンプト、選択UIプロンプト、ファイルシステムプロンプト）に分けて実装
2. **タスク4**: 実装変更の動作確認を早期に実行し、視覚的な変更を確認
3. **タスク5-7**: テストコードを段階的に更新（ユニット → 統合 → E2E）
4. **タスク8**: 全テストスイートを実行し、既存機能の互換性を総合的に確認
5. **タスク9**: ビルドを実行し、本番環境への準備を確認
6. **タスク10**: 手動テストで異なる環境での動作を最終確認

この順序により、実装とテストを段階的に進め、各段階で問題を早期に発見できる。
