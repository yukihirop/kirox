# 実装計画

## タスク一覧

- [ ] 1. リポジトリパース処理の拡張
- [x] 1.1 ブランチ抽出機能の実装
  - `owner/repo#branch`形式の文字列を解析してowner、repo、branchに分割する処理を実装
  - `#`がない場合はbranchをundefinedとして扱う
  - `#`が複数ある場合は最初の`#`をセパレータとし、以降を全てブランチ名として認識
  - `owner/repo#`形式（空ブランチ名）の場合はbranchをundefinedに正規化
  - ブランチ名にスラッシュ（例: `feature/new-api`）が含まれる場合も正しく認識
  - _Requirements: 3.1, 3.2, 3.3, 3.5_

- [ ] 1.2 リポジトリ形式の検証強化

  - エラーメッセージ: "無効なリポジトリ形式です: owner/repo#branch形式で指定してください"
  - _Requirements: 3.4_

- [ ] 1.3 既存の下位互換性を確保
